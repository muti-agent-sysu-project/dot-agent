# dot-agent 编码计划：最小披露端云协同（对标已发表论文规格）

版本 2026-11-05。目标：把现有系统升级到能支撑一篇 Findings/CCF-B 层次论文的实验强度。
定位一句话：难度与敏感度双信号的端云协同，在质量约束下联合优化成本、时延、披露量。

## 竞品定位（决定差异边界）

| 系统 | 已发表 | 与本项目的关系 |
|---|---|---|
| PRISM | AAAI 2026 | 单轮问答、整句级敏感度、语义草图扰动、无回填。我们：子任务粒度、依赖图传播、假名化可逆、判别模式 |
| PrivacyChecker (微软) | EMNLP 2025 Findings | 提示层缓解，不做端云分配；其泄露率定义与评测方法借鉴 |
| DoT | WWW 2025 | 无隐私维度；其投机执行思想是我们判别模式的对照 |
| RouteLLM / HybridLLM | ICLR 2025/2024 | 难度单信号基线 |

## 不做的事

- 不重构架构、不换框架；现有分层即实验平台
- 不做差分隐私、同态加密、可信执行环境（承诺不起）
- 不做多模型多云端扩展（论文范围外）

## P0 底座修复（约 1 周）

1. 修 Router theta_default 死参数（删掉或接到 POLICY 扫描）
2. 恢复 alpha 信号：openai_compat 请求加 logprobs（llama.cpp 与 DeepSeek API 均支持），
   信号从"只有一致率"回到两信号
3. evidence 工作流（sources 问答路径）接入 PrivacyGuard
4. 计量增强：每次云端调用记录实际发送文本的实体残留计数（披露地面真值），
   面板逐次调用表加"云端所见"列

验收：单测全绿；演示请求四指标（质量、token、时延、披露）齐出。

## P1 评测基础设施（2 至 3 周，论文核心）

1. sensitive-bench 生成器（eval/sensitive_bench/）
   - 底座：GSM8K 中文抽样、自建中文多步智能体任务（预约、报销、病例整理、行程改签）
   - 程序化注入实体：中文姓名、手机号、身份证、住址、金额、病史描述，带 ground truth 标注
   - 规模：每域至少 300 条，总量 1500 以上
2. 自动评分（eval/scoring/）
   - 正确性：数值与包含匹配为主，争议样本本地 LLM 判分
   - 披露率：云端 prompt 中残留注入实体数除以总数（可计算、可复现）
   - 成本与延展：沿用现有 meter
3. 实验 harness（eval/harness/）
   - 统一跑：系统（本项目 5 模式）与基线 × 任务域 × 3 个随机种子
   - 产出：四指标主表、消融表、帕累托曲线（质量-披露、成本-披露）
   - 自动生成 LaTeX 表格

验收：一条命令复现主表；数字与 SQLite 账本对得上。

## P2 机制强化（3 至 4 周，与 P1 并行）

1. 敏感度判定升级：本地 NER（候选 OpenMed-PII-Chinese 278M，或微调小模型）
   加规则融合；在自建标注集上报 P/R/F1，与纯正则、Presidio、云端零样本对比
2. 判别模式做深：候选数 k 与温度消融、判别提示消融、失败回退链（判别、假名化生成、
   本地降级）的系统对比
3. 假名化做细：实体类型感知替换、数字格式保持（手机号换同长度假号，保任务效用）、
   回填一致性校验（回填后实体数守恒）
4. 分配策略数据标定：用 SQLite 历史记录扫阈值、训轻量难度预测器（信号加特征的
   逻辑回归），报校准曲线；手拍参数全部换成标定值

验收：每个机制单独消融有数字支撑；规则层不再是唯一敏感度来源。

## P3 基线实现（2 周）

同一 harness 同一指标：纯本地、纯云端、隐私关闭（DoT 形态）、一律假名化、
统一扰动（PRISM 简化复现）、判别模式关闭对照。

验收：主表基线列齐全，无"自家系统"特殊路径。

## P4 论文支撑（1 至 2 周）

1. 决策问题形式化：观测变量（难度、敏感度）、决策空间（四模式）、
   约束（质量下限）与目标（成本、时延、披露加权和或帕累托）
2. 披露量的形式定义与泄露上界讨论（判别模式下云端信息 = 假名化问题加候选答案）
3. 实验-section 草稿需要的全部图表由 harness 自动产出

## 里程碑与总量

- 第 4 周：P0 加 P1 完成，内部可跑全量实验（中期检查可展示）
- 第 8 周：P2 加 P3 完成，主表定稿
- 第 10 周：P4 完成，论文实验部分齐备
- 总量约 10 周，三人分工：评测与机制、基线与形式化、数据与面板可各领一块

## 风险

1. DeepSeek API 花费：全量实验预估 1500 题乘 6 系统乘 3 种子；先 100 题试跑估单价，
   种子可降到 2 个
2. AutoDL 算力：本地 NER 与判别采样都吃 GPU；278M 模型与 Qwen3-4B 可共存于现有卡
3. 撞车：PRISM 已正式发表，若审稿期间出现子任务级隐私分配新文，靠判别模式与
   依赖图传播两点保差异
4. 中文 NER 质量：先人工标 200 条验证再全量，质量不够就换微调路线

恢复后联调。
